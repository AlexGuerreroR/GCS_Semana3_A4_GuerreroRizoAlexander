# MAX Inventory (Mini-sistema)

Este repositorio contiene un paquete mínimo y auditable del sistema MAX Inventory.

## Objetivo
Registrar productos, entradas, salidas y consultar stock, manteniendo trazabilidad de cambios.

## Contenido
- Documentación: SRS, modelo de calidad, análisis del ciclo de cambio
- Configuración: ejemplo de configuración
- Código mínimo: lógica simple de inventario
- Pruebas: evidencia mínima para validar cambios

## Cómo ejecutar (demo)
Requiere Python 3.

```bash
python src/app.py
